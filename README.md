# Car_Price_Prediction
A machine learning web application that predicts the selling price of used cars based on features like company, model, year, fuel type, and kilometers driven. The app uses a Linear Regression model trained on a cleaned dataset of cars. Users can select options from dropdowns and enter kilometers driven to get a predicted price instantly.

**Features:**

Cleaned and preprocessed car dataset

Linear Regression model for price prediction

Dynamic dropdowns for car models based on company

Flask backend and HTML/Bootstrap/JS frontend

Easy-to-use interface for interactive predictions

Note: The application is not deployed yet and runs locally.

Files Included:

Cleaned Car.csv – Cleaned dataset

LinearRegressionModel.pkl – Trained model

application.py – Flask app backend

templates/index.html – Frontend template

style.css – Custom styles

Jupyter Notebook – Data cleaning, model training, and evaluation
